# Application esclave — page spectateur Fichier unique `index.html`, sans dépendance, sans build. À déposer tel quel dans `/show/` sur GitHub Pages. **Ce qu'elle fait** - écran d'accueil avec un bouton d'entrée (obligatoire pour le Wake Lock, le plein écran et l'anti-veille) ; - synchronisation d'horloge avec le serveur (algorithme de Cristian, 7 échantillons, on garde le meilleur RTT) ; - exécution des cues **à l'instant prévu**, pas à l'instant de réception ; - scènes : couleurs unies, dégradés, images préchargées, pulsation CSS, écran noir ; - groupes A / B / C tirés au sort et mémorisés → vagues, damiers, alternances ; - reconnexion automatique, resynchronisation au retour d'arrière-plan ; - mode dégradé : si le WebSocket tombe, la dernière scène reste affichée ; - avertissement photosensibilité + consigne de luminosité. **Configuration** : tout se règle par l'URL du QR code, aucune modification du fichier nécessaire. ``` https://toncompte.github.io/lightshow/show/?ws=wss://mon-serveur.example/ws ``` --- ## `index.html` ```html Light Show
